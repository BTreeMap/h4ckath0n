## $(date +%Y-%m-%d) - Adding Required Indicators to Form Labels
 **Learning:** When adding visual indicators like an asterisk (*) to form labels to denote required fields, it is essential to wrap the indicator in an element with `aria-hidden="true"`. This prevents screen readers from redundantly announcing the symbol, as the semantic `required` HTML attribute on the input field already conveys this state to assistive technologies. Additionally, when using React Testing Library, updating string queries to regex (e.g., `getByLabelText(/Label Name/)`) ensures tests remain resilient to visual label modifications.
 **Action:** Always include `aria-hidden="true"` on decorative visual indicators attached to labels. Remember to update associated RTL test queries to use regex matching to prevent test breakage when labels contain extra formatting or nested elements.
