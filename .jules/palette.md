## 2024-10-11 - Adding visually distinct Required indicators to inputs
 **Learning:** When adding visual indicators like `*` for required inputs inside `<label>` elements, it's critical to use `aria-hidden="true"` on the indicator span so screen readers don't read "star" or "asterisk" when reading the label. The `required` attribute on the input itself already semantically announces the requirement. Additionally, updating `vitest` unit tests querying for labels by text using exact strings might fail after appending the indicator, so regex label matchers (`getByLabelText(/Label Name/)`) are more robust.
 **Action:** For all future `h4ckath0n` input and form field components, when modifying visible text representations (such as appending a required asterisk or status icon), use regex for testing text labels to maintain test resilience. Also, ensure all visually decorative indicators within labels are marked `aria-hidden="true"`.
