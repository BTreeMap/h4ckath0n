## 2024-05-15 - Missing focus styles on absolute-positioned icon buttons
**Learning:** In Tailwind projects, default browser outlines are removed by preflight. Absolute-positioned icon-only buttons (like the password visibility toggle) completely lose keyboard navigation visibility if explicit `focus-visible` classes aren't added, making them inaccessible to keyboard users. Tooltips (`title`) are also essential for mouse users to understand the icon's function.
**Action:** Always explicitly add `focus-visible` utility classes (e.g., `focus-visible:ring-2 focus-visible:ring-primary focus-visible:outline-none`) and `title` attributes to custom interactive elements, especially absolute-positioned icon-only buttons. Ensure focus rings match border radii (e.g., `rounded-r-xl`).
