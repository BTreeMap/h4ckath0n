## 2024-11-20 - Adding Visual Indicators for Required Form Fields
 **Learning:** In reusable form components (e.g., `Input`, `PasswordField`), users need clear visual indicators for required fields. Appending an asterisk directly into the label is helpful, but we must use `aria-hidden="true"` to prevent screen readers from announcing it redundantly alongside the native `required` attribute. Also, React Testing Library's exact string matches for `getByLabelText("Label")` will fail if a visual indicator is appended inside the `<Label>` element, requiring regex matches like `getByLabelText(/Label/i)`.
 **Action:** Update the `Input` and `PasswordField` components to append a red asterisk with `aria-hidden="true"` to the label when the `required` prop is true. Update corresponding tests to use regex matches for `getByLabelText` to avoid breakage.
