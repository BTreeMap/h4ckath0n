## 2024-05-24 - Keyboard shortcut hints and Button isLoading state
**Learning:** Adding keyboard shortcut hints via `<kbd>` styled tags alongside using the Button component's built-in `isLoading` state (instead of manually rendering text changes) creates a more polished, accessible interaction pattern for frequent tasks like AI chat submission.
**Action:** Always consider adding keyboard shortcut hints for common actions in text areas, and prefer using built-in component loading states over manual text substitutions.
