## 2024-09-13 - Centralize Pydantic display name validation using Annotated
**Learning:** We had duplicated `@field_validator("display_name")` logic across multiple Pydantic models (password `RegisterRequest` and `PasskeyRegisterStartRequest`). When centralizing duplicated field validation in Pydantic schemas, prefer defining reusable types using `typing.Annotated` combined with `pydantic.Field` (for OpenAPI metadata like max_length) and `pydantic.AfterValidator` (for custom normalization/validation logic), rather than repeating `@field_validator` methods across multiple models.
**Action:** Use `typing.Annotated` + `AfterValidator` to define a `DisplayNameField` source-of-truth and share it across schemas, removing duplicate `@field_validator` blocks and streamlining the code towards a pure normalization pipeline.
