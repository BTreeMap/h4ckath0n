## 2025-02-09 - Centralize Pydantic Validation Logic with `Annotated`
**Learning:** Pydantic V2 allows defining reusable, declarative validation pipelines via `Annotated` types mixed with `Field` and `AfterValidator`. When a field in a model is typed as `Annotated[str, Field(max_length=200)]`, and the model field itself specifies *additional* metadata like `Field(description="...")`, Pydantic successfully merges them without overwriting the inner constraints. This pattern beautifully satisfies FP goals by keeping logic explicit, composable, and centralized instead of spreading `field_validator` class methods throughout multiple schema classes.
**Action:** Always prefer `Annotated` with functional validators (`AfterValidator`, `BeforeValidator`) to extract shared validation logic, avoiding duplicate `@field_validator` boilerplate.
