## 2024-07-28 - Extract pure scope manipulation helpers
**Learning:** The CLI tools for user management had duplicated, mutation-heavy logic for handling string-based authentication scopes (parsing, modifying sets, then serializing directly). It's also important to update related imports across the entire test suite when moving or removing public exports (like `_normalize_scopes` in `h4ckath0n.cli`).
**Action:** When adding scope modifications (e.g. CLI operations, dependencies), always use the pure functional helpers in `h4ckath0n.auth.authz` (e.g. `add_scopes`, `remove_scopes`, `normalize_scopes`, `parse_scopes`) to enforce deterministic normalization and order-preservation, rather than managing the ad-hoc sets manually. Also, when refactoring out CLI module exports, use `find tests` to explicitly identify test files needing import updates to prevent `ImportError` on test collection.
