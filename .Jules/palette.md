## 2025-02-12 - Visual feedback for required form inputs
 **Learning:** Standard HTML `required` attributes are functionally useful, but a visual red asterisk alongside the input's Label improves UX clarity significantly. When augmenting React elements with visual indicators that duplicate the semantic state (like `*` for `required`), placing `aria-hidden="true"` on the visual indicator ensures it does not spam screen readers with "asterisk" when navigating labels. In `vitest` tests with React Testing Library, updating text matchers from exact strings (e.g. `getByLabelText("Email")`) to regex matches (e.g. `getByLabelText(/Email/)`) prevents test brittleness when visually augmenting labels.
 **Action:** Apply this pattern dynamically: modify `Input` and `PasswordField` components to optionally read the `required` prop and automatically append a visually hidden asterisk if present.
