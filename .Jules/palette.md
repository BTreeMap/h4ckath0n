## 2023-10-14 - Required Indicator Implementation
**Learning:** Adding the native `required` attribute to form inputs on Auth pages directly alters browser submission behavior. This can cause React Testing Library tests that historically checked for field existence or text to break if they relied on exact matches without considering the new visual elements (like `*`), and it fundamentally changes the Auth flow requiring E2E testing to ensure passkeys and standard password flows aren't blocked by native browser validation tooltips.
**Action:** When adding visual indicators like `*` for required fields, always use `aria-hidden="true"` to maintain accessibility, ensure the React Testing Library queries are updated to use regexes if necessary, and always run `npm run test:e2e` when touching form fields on Login/Register pages.
